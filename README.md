# LAK風キーキャップジェネレータ

LAKスタイルのロープロファイルキーキャップを、ブラウザ上でパラメータを調整しながら設計し、3Dプリント用のSTL / 3MF / OpenSCADで出力できるツールです。Kailh Choc V2（MX互換の十字軸）用です。

ZMK Studio / Vial対応のキーボードに直接つなぐと、キーマップを読み込んでLegend（刻印）付きのキーキャップを全キー分まとめて作れます。

**▶ デモ：https://kamabokoz.github.io/LakStyleKeycapGenerator/**

![プレビュー](docs/preview.png)

## 画面の構成

- **左**：3Dプレビュー（斜め・横・底面・3キー並び・断面・全体・サイズ見本）と、その下の**フィラメントのバー**（どのフィラメントが何を印刷するか）。バーを押すと出力タブの割り当て表に移ります。
- **右のタブ**：「形状」「キーマップ」「Legend」「天面アート」「出力」。スマホでは画面下のタブバーになります。選んだタブは次に開いたときも残ります。
- **保存ボタン**：右列の下（スマホではタブバーの上）に常に表示される1つのボタンです。出力タブで選んだもの（キーの形だけ／全キー／選択中のキー／Legendのサイズ見本）と形式に合わせて「STLを保存」「3MFを保存」などに変わります。
- **上部**：「プリセット・履歴」（保存した設定を開くパネル）と「Xに投稿」。

## 主な機能

- **形状のパラメータ調整**：キーピッチ、外周帯と中央部の段差（傾斜幅・肩R・裾R）、天面の曲面（球面／円筒、凸／凹）、肉厚、十字穴の寸法など。3D・断面プレビューで確認しながら調整できます。
- **キーマップからLegendを生成**：ZMK（USB / Bluetooth、ZMK Studio RPC）とVial（USB、WebHID）のキーボードからキーマップと全レイヤーを読み込み、キーごとに表示するレイヤー・位置・文字を設定できます。ホストPCのJIS / US配列に合わせて記号を表示します。文字の太さ（標準／太字）はレイヤーごとに選べます。
- **SVG画像のLegend**：SVGファイル（ロゴ・アイコン）を追加して、文字の代わりに印字したり、ロゴとして文字と並べて印字したりできます。濃い色の部分（または描かれた部分すべて）が印字され、倍率で大きさを調整できます。彫り込み・浮き彫り・3MFの色分けにも対応します（engraved.scadには入りません）。Shift・Enter・Backspace・矢印・音量・メディア操作・⌘⌥⌃などのアイコン47種を内蔵しており、「おすすめの画像から選ぶ」で追加できます。「キーの文字をアイコンに置き換える」で、Shift・Enter・矢印・音量などの文字を一括でアイコンにできます（元にも戻せます）。
- **天面アート**：複数のキーの天面にまたがる大きな絵を印字できます。絵は**グループ**ごとに好きな位置・大きさ・向きで置け、1枚のキーボードに複数の絵を並べられます（例：左手側に山、右手側に月、親指キーに肉球）。1つのグループには色ごとに分けたSVG（同じアートボードから書き出したもの）をまとめて読み込むと、SVGの原点をそろえて重ね、SVGごとのフィラメントで印字します。配置図では絵をクリックするとそのグループを選べ、ドラッグで移動、丸いつまみで回転〔Shiftで15°刻み〕、角で拡大縮小できます（幅・高さ・位置・回転は数値やボタンでも調整可）。「縦横比を保つ」を外すと縦と横を別々に伸縮でき、配置図の角で縦横を自由に、辺のつまみで横だけ・縦だけを伸ばせます（Shiftを押しながら角をドラッグすると比率を保ちます）。グループは「複製」で同じ絵をいくつも置けるほか、手前／奥の入れ替え、表示の切り替え、SVGを別のグループへ移すこともできます。重なった部分は上にあるグループ（グループ内では上にあるSVG）が優先されます。「サンプルの絵・図形から追加」には、太陽と波と山・雪山と朝日・青海波・桜吹雪・月と星空・回路パターンの横長の絵と、肉球・流れ星・桜のワンポイントの絵（すべてオリジナル、色ごとに分けたSVG）に加えて、丸・四角・角丸四角・三角・ひし形・六角形・星・ハート・輪・矢印・十字・ストライプのシンプルな図形（1色）を用意しています。図形は縦横比を外して伸ばせば、楕円や帯、長方形としても使えます。同じSVGは `samples/art/`（図形は `samples/art/shapes/`）にもあります。SVGを追加すると、SVGで一番多く使われている色がそのフィラメントの色になり、同じ色のフィラメントがあればそれを使います。3MFでは別パーツ、STLでは `art/` フォルダに出力されます。各キーの天面（中央部）で切り取られ、キーのない部分は無視されます。Legendを優先してアートを抜くか、アートだけにするかを選べます（engraved.scadには入りません）。印字する範囲は「天面の中央部のみ」と「外周帯も含める」から選べます。外周帯も含める場合、段差が斜面の天面（標準のLAK形状・なだらか）では段差を含む天面全体に、垂直な段差では外周帯と中央部に印字します。天面アートが有効なときの3MFは、キーをキーボードと同じ位置・向きで並べて出力します（「並べ方」で格子状に詰めることもできます。プレートからはみ出す場合はスライサーで調整してください）。
- **フィラメントの割り当て**：出力タブの「フィラメントの割り当て」表に、本体・Legend（レイヤーごとに色分けした場合はレイヤーごと）・天面アートのSVGごとの用途が並び、それぞれのフィラメント番号と色をまとめて決められます。同じ番号にした用途は同じフィラメントになり、色を変えるとその番号を使うすべての用途に反映されます。プレビューはこの色で表示されます。「3MFにフィラメントの色を書き込む」（初期値はオフ・試験的）をオンにすると、3MFにも色を書き込み、Bambu Studio / OrcaSlicerで開いたときに色が付きます。
- **全体プレビュー**：キーマップを読み込むと、3D表示に「全体」が出ます。キーボード全体を実際の配列（回転キーを含む）で並べ、Legend・マーク・ホーミング突起・天面アートをフィラメントの色で表示します。ホイールで拡大縮小でき、この表示のままXに投稿すると、投稿画像もキーボード全体になります。
- **レイヤーキーのマーク**：MO・TG・TOなどのレイヤーキーと、ベースレイヤーのLayer-Tapに、切り替え先レイヤーを表すマーク（丸・四角・三角・バー）を印字できます。3MFで「レイヤーごとに色分け」にすると、マークは切り替え先レイヤーの色になります。レイヤー切り替えだけのキーは文字を省いてマークだけにもできます（マークはengraved.scadには入りません）。
- **ホーミング突起**：バー／ドットの形、長さ・太さ・高さ・位置を調整できます。突起は天面の曲面に沿って付くので、へこんだ天面でも高さがそろいます。キーマップを読み込んでいるときにオンにすると、まずF・Jキーに付き、プレビューも突起の付いたキーに切り替わります。付けるキーはキーごとに変えられます。
- **Legendのサイズ見本**：出力タブで「Legendのサイズ見本」を選び、見本の文字と大きさ（例：`1.5, 2, 2.5, 3`）を入れると、Legendが潰れないかを試し刷りする3MFを保存できます。キーの形は作らず、薄い1枚の板（彫り込みは深さ＋0.6mm、浮き彫りは1mm）を格子状に区切り、大きさごとのマスに今のフォント・彫り込み／浮き彫りの設定で見本の文字を印字します。各マスの見本の下に大きさ（例：`2.5`、標準と太字の両方を作る場合は `2.5N` / `2.5B`）を刻むので、印刷後もどの大きさか分かります。マスは文字に合わせた大きさで、大きさごとの行を左詰めに積むため（階段状の板）、フィラメントは数gで済みます。「3Dでプレビュー」で3D表示が「サイズ見本」に切り替わり、板の寸法・厚さ・おおよその重さ（PLA）と一緒に確認できます（見本の文字や大きさを変えるとプレビューも追従します）。
- **Legendのフォント**：日本語対応8種・英数字向け5種のWebフォントに加えて、PCにインストールしたフォントや、手元のフォントファイル（TTF / OTF / WOFF / WOFF2）も使えます。
- **Legendは彫り込み（面一）または浮き彫り**：彫り込みの場合は、はめ込み用のLegendパーツも出力するので、2色印刷（AMSなど）に使えます。
- **出力形式**
  - STL（ZIP）：キーごとの本体、はめ込みLegend、刻印用OpenSCAD
  - 3MF：全キーをプレートに並べ、各キーを「本体＋Legend」のパーツにした1ファイル（Bambu Studio / OrcaSlicer向け、フィラメント番号つき）。Legendは「レイヤーごとに色分け」にすると、レイヤーごとに別パーツ・別フィラメントになります（例：Baseは黒、Numは緑）。
  - OpenSCAD：同じ形状を再現できるパラメトリックなソース
- **プリセットと保存履歴**：ブラウザ内に保存し、名前の変更や呼び出しができます。
- **Xに投稿**：プレビュー画像を作り、パラメータを埋め込んだリンク（`#k=…`）と一緒に投稿できます。リンクを開くと同じ形が表示されます。作業中の画面で共有リンクを開いた場合は、それまでの設定を保存履歴に残し、「元に戻す」で戻せます。投稿画面の「画像の見た目を調整」で、3Dビューワーをその場で回転・拡大縮小したり、斜め／横／3キー並び／全体／真上を切り替えたりでき、投稿画像がその見た目で作り直されます。

## 使い方

1. デモページを開くか、このリポジトリをダウンロードして `index.html` をブラウザで開きます。ビルドは不要です。
2. 「形状」タブのパラメータで形を調整します。初期値はオリジナルのLAKに近い形です。
3. 1キーだけ作る場合は、そのまま保存ボタン（「STLを保存」）を押します。出力タブの「キーの形だけ（1個）」の状態です。
4. Legend付きで作る場合は「キーマップ」タブで次のように進めます。
   1. DYA Studio / ZMK Studioは先に切断してください。
   2. ZMKのキーボードをUSBでつなぐ場合は「ZMK（USB）」を押してポートを選び、キーボードのアンロック操作（`&studio_unlock`）を押すとキーマップが読み込まれます。
   3. Bluetoothの場合は「ZMK（Bluetooth）」を押してキーボードを選び、アンロック操作をします。一覧には、ZMKキーボードが広告しているバッテリーサービスを持つ機器が表示されます。キーボードが出ない場合は「すべてのデバイスから選ぶ」を使ってください。
   - Vialのキーボードは、Vialアプリを閉じてから「Vial（USB）」を押して選びます。アンロックは不要です。キー配列（レイアウトオプションを含む）もキーボードから読み込みます。VIAのみ（Vialでない）のキーボードは、先にVIA用のキーボード定義JSONを「ファイルから読込」で読み込んでから接続してください。
   - Vialで保存した `.vil` ファイルも「ファイルから読込」で読み込めます。`.vil` にはキー配列が入っていないため、キーボード定義（vial-qmkの `keyboards/…/keymaps/vial/vial.json`）も一緒に選ぶと実際の配列で表示されます（定義がない場合は行×列の並びで表示します）。
   うまくつながらない場合は「接続ログ」に各段階の結果が出ます。
   4. 配列図でキーを選び、表示するレイヤーと位置を設定します。「位置の微調整」で0.1mm単位でずらせます。ホーミング突起を付けるキーもここで選べます。フォントや大きさ、太さ、マーク、画像は「Legend」タブ、大きな絵は「天面アート」タブで設定します。
   5. 「出力」タブで作るもの（全キー／選択中のキー）と形式（STL・3MF）、フィラメントの割り当てを決めて、保存ボタンを押します。

キーボードがない場合は「サンプルで試す」で動作を確認できます。

### 2色印刷（Bambu Studioの例）

- **3MFで出力した場合**：ファイルを開くだけで、各キーが本体とLegend（レイヤーごとに色分けした場合はレイヤーの数だけ）のパーツになっています。フィラメントの割り当てを確認して印刷してください。色分けした場合、プレビューのLegendはフィラメント番号ごとの色で表示されます。
- **STLで出力した場合**：同じ番号の `keys/XX.stl` と `inlay/XX_legend.stl` を同時に読み込み、「1つのオブジェクトとして読み込む」を選んでから、Legendパーツに別のフィラメントを割り当てます。

細い文字や小さい文字が潰れないか心配な場合は、先に出力タブの「Legendのサイズ見本」の3MFを印刷して、読める最小の大きさを確かめてから本番のLegendの大きさを決めると確実です。

彫り込みの深さを積層ピッチの倍数（0.2mmピッチなら0.4 / 0.6mm）にすると、色の境目がきれいに出ます。

### 印刷のヒント

- 十字穴の寸法はプリンタによって合い方が変わります。「ステム」の欄にFDM用と光造形用のプリセットがあります。きつい・緩い場合は0.05mm刻みで調整してください。
- 初期値の形は、天面を上にしてそのまま印刷できます（サポート不要）。

## 対応ブラウザ

| 機能 | 対応 |
| --- | --- |
| 形状の調整・STL / 3MF出力 | 主要なモダンブラウザ |
| USB接続（Web Serial） | PCのChrome / Edge |
| Bluetooth接続（Web Bluetooth） | Chrome / Edge（Android含む）、iOSはBluefyなど |
| 画像付きでXアプリに共有 | 共有メニューでファイルを渡せる環境（主にスマホ） |

USB / Bluetooth接続にはhttps（GitHub Pagesなど）か、ローカルファイルとして開く必要があります。

## Xへの投稿と共有リンク

投稿画面の「キーキャップの名前」を変えると、投稿画像の見出し（初期値は「LAK風キーキャップ」）、投稿文の「」内、共有リンクに入る名前がまとめて変わります。投稿文を手で書き換えていても、「」で囲んだ名前の部分だけが置き換わります。

GitHub Pagesなどhttpsで公開したページでは、そのURLが共有リンクの公開先として自動で使われます。別の場所で使う場合は、投稿画面の「リンクの公開先URL」に公開ページのURLを設定してください。

リンクの `#k=` 以降には、初期値から変えたパラメータだけがエンコードされています。サーバーには送信されません。

## 開発

依存パッケージもビルド工程もありません。ファイルを編集してブラウザで開き直すだけで確認できます。

```sh
# メッシュが閉じた形状になっているかの検証（Node.js 18以降）
node tests/mesh-check.js

# 1ファイルにまとめたHTMLを生成（オフライン配布用） → dist/lak-keycap-generator.html
python3 tools/build_single.py
```

### GitHub Pagesでの公開

リポジトリの Settings → Pages で「Deploy from a branch」を選び、`main` ブランチの `/ (root)` を指定します。公開後は、`index.html` の `og:image` とこのREADMEの `kamabokoz` を自分のURLに書き換えてください。

## 既知の制限

- 3MFのフィラメント自動割り当ては、Bambu Studio独自の形式に合わせて書いています。スライサーのバージョンによっては反映されないことがあります。その場合でもパーツ構成は残るので、手動で割り当てられます。
- Bluetooth接続で一度つないだキーボードの名前を変えた場合などは、一覧に出なくなります。その場合は「すべてのデバイスから選ぶ」を使ってください。
- オリジナルのLAKにある、底面から少し飛び出したステムや裏側の形状は再現していません。

## 注意事項

このツールは非公式のファンメイドです。オリジナルの「LAK」キーキャップの製造・販売元とは関係ありません。初期値の形状は、公開されている図面と写真から推定したもので、実物の寸法とは異なる場合があります。
